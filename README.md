# Azure Event-Driven Data Processing Pipeline

A portfolio project demonstrating an event-driven, serverless data processing architecture on Microsoft Azure.

## Planned Architecture

- Azure Blob Storage
- Azure Functions
- Azure Cosmos DB
- Azure Managed Identity
- Azure RBAC
- Azure Monitor / Application Insights
- Bicep Infrastructure as Code

## Goal

The project demonstrates practical Azure cloud engineering concepts including event-driven processing, serverless computing, cloud storage, NoSQL databases, identity and access management, monitoring, and Infrastructure as Code.
